# Aero symbol exploration — round 2

Fresh symbol-only exploration created from the current HANDOFF brief.

Constraints:
- no Aero wordmark inside the symbol;
- angular/geometric construction;
- no curved/swooping ribbon direction;
- compact enough for a 32–40 px app/header icon;
- designed against the current dark Aero UI;
- uses the current lilac / pink / ice palette;
- no concept in this folder is approved branding yet.

Concepts:
1. **Vector Notch** — compact forward vector with a hard internal cut.
2. **Twin Wing** — mirrored angular wings around a diamond core.
3. **Prism Cut** — faceted enclosure split by a diagonal motion cut.
4. **Flight Core** — three-piece aerodynamic mark around a central core.
5. **Crosswind** — stacked speed bars with an asymmetric leading cut.
6. **Delta Frame** — open triangular frame with a reinforced lower core.

Open `index.html` to compare all six at icon size and large size.

Do not integrate any of these into the production header until one is explicitly selected.
